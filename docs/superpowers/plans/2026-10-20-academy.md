# Academy Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans para executar sequencialmente com testes.

**Goal:** Entregar a plataforma educacional funcional descrita no prompt mestre.
**Architecture:** SPA estática com conteúdo versionado e exemplo Python isolado.
**Tech Stack:** React, TypeScript, Vite, Markdown, Shiki, Zod, Vitest, Playwright, FastAPI.
**Spec:** docs/superpowers/specs/2026-10-20-academy-design.md

## Global Constraints
pt-BR; R$ 0; sem login obrigatório; sem serviços pagos; sem merge/deploy; commits por tarefa; sem worktree adicional.

## Review Focus
- Dados locais corrompidos não bloqueiam leitura.
- Referências editoriais inválidas quebram build.
- HTTP upstream inválido não vaza detalhes internos.
- Navegação e árvore de arquivos funcionam por teclado/móvel.
- Conteúdo Markdown não executa scripts.

## Tarefa 1 — Conteúdo e fundação
Arquivos: package.json, content/*, src/lib/content.ts, src/lib/search.ts, src/lib/storage.ts, src/test/content.test.ts.
Interfaces: exportar catalog, chapters, search(query), validateCatalog(input), readPreference(key, fallback).
- [ ] Escrever testes para pesquisa sem acentos, referências inválidas e armazenamento corrompido; executar e observar falhas.
- [ ] Implementar schema, índice, preferências e capítulos originais; rodar npm test e npm run validate:content.
- [ ] Commit feat: add validated educational content and local search.

## Tarefa 2 — Exemplo Python
Arquivos: examples/fastapi-ollama/app/{main,config,models}.py, routes/chat.py, integrations/ollama.py, tests/test_chat.py.
Interfaces: create_app(settings, transport=None), POST /api/chat, GET /health.
- [ ] Testes de sucesso, entrada inválida, timeout, conexão, status e payload upstream inválido; observar falhas.
- [ ] Implementar camadas e README reproduzível; executar pytest.
- [ ] Commit feat: add tested FastAPI Ollama educational project.

## Tarefa 3 — Interface pública
Arquivos: src/components/*, src/pages/*, src/App.tsx, src/styles.css, e2e/*.
Consome catalog/search e arquivos Python reais via importação raw. Produz rotas /biblioteca, /capitulos/:id, /arquiteturas, /projetos/fastapi-ollama, /trilhas, /recursos, /glossario, /busca.
- [ ] Testes de leitura, busca, progresso, seleção de arquivo e etapas do diagrama; observar falhas.
- [ ] Implementar componentes responsivos, tema, leitor, diagramas, catálogo e roadmaps.
- [ ] Executar testes, build e E2E desktop/móvel; verificar screenshot e acessibilidade.
- [ ] Commit feat: build accessible interactive academy.
